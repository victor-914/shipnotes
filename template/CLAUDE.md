# shipnotes content repo

Blog drafts written from project outcomes, reviewed as pull requests. Use the `shipnotes` skill for anything about drafts.

- Never add a number that isn't in a draft's `facts:` frontmatter. Run `npx -y github:victor-914/shipnotes check <file>` before committing.
- Never edit the `facts:` block.
- Edit drafts on their PR branch. Publishing = merging the PR, only when the author says so.
